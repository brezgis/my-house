# Model catalogue

Every model in `site/assets/models/`, one row each. All are glTF 2.0 (`<id>/<id>.gltf` + `<id>.bin` + `textures/`) and load in three.js r170 `GLTFLoader` with no Draco, meshopt or KTX2 decoders (verified: every file parses, every referenced file exists, no compressed-geometry or compressed-texture extension is used; the only `extensionsRequired` anywhere is `KHR_texture_transform`, which GLTFLoader handles natively).

Conventions: sizes are the bounding box **width (X) x height (Y) x depth (Z) in feet**, computed from the actual vertex data with node transforms applied; every model is authored in metres (unit fixes already baked in, see notes), so multiply by 3.28084 at load as for the rest of the scene. "Front" is the side facing the viewer when you look from +Z toward the origin; confidence in brackets is from rendered front and side views (`research/model_sheets/`). Poly Haven assets consistently face +Z. Origin: "bottom-centre" means the origin is at floor level under the middle of the bounding box. Animated models list their clip names in Notes. `New` = added in this buying round (2026-11-11).
